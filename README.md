# Pasapalabra Game

Un juego interactivo inspirado en el clásico *Pasapalabra*, desarrollado en **Python con Pygame**.  
Incluye animaciones, botones dinámicos y una interfaz visual pensada para que sea divertida y fácil de usar.

## Descripción

Este proyecto fue creado como parte de un trabajo práctico de programación, con el objetivo de aplicar conceptos de eventos, interfaces gráficas y lógica de juego en Python.  
El jugador responde preguntas de distintas letras del abecedario y el juego evalúa sus respuestas, mostrando aciertos y errores en tiempo real.
