# Pasapalabra Game

**Pasapalabra Game** es un proyecto desarrollado en **Python** usando **Pygame**, inspirado en el clásico juego televisivo.  
El objetivo es responder correctamente las palabras asociadas a cada letra del rosco antes de que se acabe el tiempo ⏰.

## Características principales

- Interfaz visual creada con **Pygame**.  
- Control del tiempo y sistema de puntuación.  
- Animaciones y efectos de sonido personalizados.  
- Base de datos con preguntas y respuestas organizadas por letra.  
- Sistema de colores para respuestas correctas e incorrectas.
